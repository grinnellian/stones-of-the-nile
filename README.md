# Stones of the Nile

Browser-based ancient Egypt economy tycoon.

Build pyramids by designing logistics networks across ancient Egypt. Each pyramid construction theory (ramps, water shafts, cast-in-place) is a different systems architecture with different bottlenecks to optimize. Sustained output matters, not one-off delivery.
